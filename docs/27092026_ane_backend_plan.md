# ANE backend, first primitive: publish as a draft PR (plan)

Category: Plan (dated). Date: 2026-09-27. Branch: `feat/ane-backend`. Status: draft PR, not
for merge until the primitive is wired into prefill and gated there.

## What this is

Task A0 (2026-08-28, see the top of `todo.md` and the ANE rows in `docs/c4model.md`): a second
compute path over CoreML that reaches the Apple Neural Engine. `src/ane.m` exposes
`sg_ane_open`, `sg_ane_matmul`, `sg_ane_on_ane`, `sg_ane_shape` and two diagnostics;
`tests/test_ane.c` gates one fp16 linear layer against an independent double-precision oracle
built from the generator's `weights.f16`. The measurement harnesses live in `tools/ane_*.py`
and `tools/machine_census.py`.

It is done and gated on hardware, and NOT wired in: nothing calls `sg_ane_matmul` from
`sg_gpu_forward` or `sg_gpu_prefill`. The next task is splitting prefill GEMM between Metal
and the ANE at a measured ratio, gated on unchanged `gen_ids`.

## How it got here

The work sat uncommitted in a checkout. It was carried over onto a branch cut from main after
PR #2 (`df3b539`): the tracked diff (`Makefile`, `surge.h`, `docs/c4model.md`, `todo.md`)
via `git diff --binary HEAD` and `git apply -3`, plus an explicit list of eight untracked
files. The generated fixture (`tests/fixtures/ane/`, about 4 MB) is not committed; it is
regenerated by `make ane-fixture` and is now in `.gitignore`.

## Changes made while carrying it over

- Personal absolute paths parameterized: `ANE_PY ?= $(HOME)/models/ane-venv/bin/python`
  (and the existing `GGUF`/`PY` gate defaults the same way); the tools' GPU-arm interpreter
  default is `SURGE_GPU_PY`, falling back to `~/models/dsv4-venv/bin/python`, defined once in
  `tools/ane_gemm_probe.py` and imported by `ane_envelope.py` and `ane_vs_all.py`; docstrings
  name the venv by role rather than by path. Comment paths in `surge.h` use `~/`.
- `todo.md`: the A0 entry keeps its ANE content; its venv path is replaced by `ANE_PY`.
- `tools/machine_census.py` checked: it embeds no hostname, serial or user path. At runtime it
  records process command lines of contending jobs (first 110 characters) into the result it
  returns, so a result file written from it can contain local paths.

  `test_ane` SKIPs without a fixture, as designed. `test_cli_prefill` 11 cases,
  `test_cli_bench` 19 cases.

- The Python tools were byte-compiled only; the measurement harnesses were not rerun (they
  pin the GPU and ANE for minutes and are not part of `make check`).

## Known limits

- `tools/ane_build_model.py` needs `coremltools` from a venv, which breaks the
  no-third-party rule at build time (not at run time).
- The throughput figures in `docs/c4model.md` and `surge.h` come from the harnesses' runs on
  2026-08-28; no result file from those runs is committed.
