# surge M0-M2 Implementation Plan (skeleton, GGUF, tokenizer, CPU reference, Metal bf16)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A correct (slow) engine: mmap a GGUF, tokenize, run a full CPU-reference forward
pass validated against mlx-lm, and a Metal bf16 decode path that matches the CPU
reference byte-exactly at temp 0.

**Architecture:** Plain C11 + one Objective-C file for Metal. Every op has a scalar CPU
implementation in `ref.c` (the oracle); Metal kernels are tested per-op against it, then
end-to-end greedy decode must match exactly. Weights stay mmap'd; nothing is copied.

**Tech Stack:** C11, Metal (Metal.framework), tinytest-style asserts (fanpro
convention), Python only in `tools/` for fixture generation via the dsv4-venv
(mlx-lm 0.31.3, transformers).

## Global Constraints (from the spec, verbatim where numeric)

- No dependencies beyond macOS frameworks. snake_case. Makefile + compile_flags.txt.
- Exact-correctness model: `Qwen/Qwen3.5-2B` bf16 safetensors (same `qwen3_5` arch as
  the 27B; chosen because disk cannot hold a 56 GB bf16 27B alongside the quants).
- Production model for M0/M3+: `unsloth/Qwen3.6-27B-GGUF` file `Qwen3.6-27B-Q8_0.gguf`
  (26.63 GiB). Text path only; ignore `mmproj-*.gguf`.
- mlx-lm comparison interpreter: `/Users/macmini/models/dsv4-venv/bin/python`
  (mlx 0.32.0, mlx-lm 0.31.3).
- Metal bf16 decode must equal `ref.c` greedy byte-exactly at temp 0: kernels must use
  deterministic reduction order (no atomics, fixed-tree threadgroup reductions).
- M1 acceptance vs mlx-lm (cross-framework, not bit-exact): 100 percent top-1 agreement
  over the fixture set and max |logit delta| < 1e-2.
- ASan debug build target (`make debug`) must stay clean for every task.
- No em dashes in any file. Commits without AI attribution lines.

#define TINYTEST_H
#include <stdio.h>
#include <stdlib.h>
static int tt_checks = 0, tt_fails = 0;
#define tt_assert(cond, ...) do { tt_checks++; if (!(cond)) { tt_fails++; \
